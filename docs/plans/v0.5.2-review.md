# Recorder Content Cleanup Dependency Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep recorder-owned data views and their backing index intact whenever an earlier content cleanup dependency fails.

**Architecture:** Preserve the recorder's existing ownership flags as the cleanup state machine. After dashboard cleanup, derive the data-view gate from both the default-restore result and the remaining dashboard ownership; after data-view cleanup, derive the index gate from the remaining data-view ownership. Do not add a second state representation.

**Tech Stack:** Rust 2024, Tokio, wiremock, elasticctl transport and API modules

**Spec:** [`docs/specs/elasticctl-content-design.md`](../specs/elasticctl-content-design.md) section 13, especially lines 595-602

## Global Constraints

- Fix only review finding `V052-001` from `docs/reviews/v0.5.2.md`.
- A dashboard cleanup failure retains every owned data view and the backing marker index for the `Drop` retry.
- A data-view cleanup failure retains the backing marker index for the `Drop` retry.
- `NotFound` still clears ownership and counts as successful cleanup for that object.
- Default-restoration failure keeps its existing gate over all data-view and backing-index cleanup.
- Cleanup errors remain classified and must not include server response bodies or private identity.
- Do not change recorder fixtures, request bodies, route order, or any non-content cleanup path.
- Use `cargo test -p xtask -- --test-threads=6` for the focused crate gate.

```rust
#[tokio::test]
async fn dashboard_cleanup_failure_retains_data_views_and_their_index() {
    let server = MockServer::start().await;
    Mock::given(method("GET"))
        .and(path(format!("/api/dashboards/{DASHBOARD_ID}")))
        .respond_with(ResponseTemplate::new(500).set_body_json(json!({
            "message": "private dashboard cleanup identity"
        })))
        .mount(&server)
        .await;
    let transport = mock_transport(&server);
    let mut session = RecordingSession {
        transport: &transport,
        ownership: CleanupOwnership {
            dashboard: true,
            dashboard_data_view: true,
            data_view_index: true,
            ..Default::default()
        },
    };

    assert!(session.cleanup().await.is_err());
    assert!(session.ownership.dashboard);
    assert!(session.ownership.dashboard_data_view);
    assert!(session.ownership.data_view_index);
    let requests = server.received_requests().await.expect("requests");
    assert!(requests.iter().any(|request| {
        request.url.path() == format!("/api/dashboards/{DASHBOARD_ID}")
    }));
    assert!(requests.iter().all(|request| {
        !request.url.path().starts_with("/api/data_views/data_view/")
            && !request.url.path().starts_with(&format!("/{DATA_VIEW_INDEX}"))
    }));
}
```
