# elasticctl 0.2.4 Review Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every issue validated by the post-v0.2.3 review, prove the result across supported targets, and publish v0.2.4 to GitHub and crates.io.

**Architecture:** Enforce safety at filesystem and HTTP response boundaries while preserving the public Rust API and valid CLI output. Each behavioral change starts with a failing regression, then the release repeats package, CI, and live gates before the irreversible crates.io step.

**Tech Stack:** Rust 1.97.1, Cargo, reqwest, serde_json, tempfile, wiremock, Bash, jq, GitHub Actions, cargo-dist, GitHub CLI, crates.io.

## Global Constraints

- Keep the public Rust API source-compatible for this patch release.
- Keep valid CLI JSON and human-readable output unchanged.
- Keep config paths, profile resolution, and relative `--config` paths working.
- Keep valid historical NDJSON bundles readable.
- Add no deployment-specific URLs, credentials, identifiers, or raw live data.
- Fix every validated current-review issue in v0.2.4; leave no planned v0.2.5 from this review.
- Work sequentially on local `master`. Do not use a worktree or subagent unless the user asks.
- Do not publish until the exact v0.2.4 commit passes local, CI, preflight, live, and GitHub Release verification.

```rust
#[test]
fn save_atomically_replaces_a_permissive_existing_file() {
    use std::os::unix::fs::{MetadataExt, PermissionsExt};
    let dir = tempfile::tempdir().unwrap();
    let path = dir.path().join("config.toml");
    fs::write(&path, "old\n").unwrap();
    fs::set_permissions(&path, fs::Permissions::from_mode(0o644)).unwrap();
    let old_inode = fs::metadata(&path).unwrap().ino();

    sample().save(&path).unwrap();

    let metadata = fs::metadata(&path).unwrap();
    assert_ne!(metadata.ino(), old_inode, "save must replace, not truncate");
    assert_eq!(metadata.permissions().mode() & 0o777, 0o600);
    assert_eq!(Config::load(&path).unwrap().current, "default");
}

#[cfg(unix)]
#[test]
fn save_replaces_a_symlink_without_writing_its_target() {
    use std::os::unix::fs::symlink;
    let dir = tempfile::tempdir().unwrap();
    let target = dir.path().join("target.toml");
    let path = dir.path().join("config.toml");
    fs::write(&target, "do not replace\n").unwrap();
    symlink(&target, &path).unwrap();

    sample().save(&path).unwrap();

    assert_eq!(fs::read_to_string(&target).unwrap(), "do not replace\n");
    assert!(!fs::symlink_metadata(&path).unwrap().file_type().is_symlink());
}
```
