# v0.8.2 development review

The runtime is unchanged from v0.8.1; the independent 0.8.1 slice and
whole-branch reviews stand for that code. This review covers the new protocol
tests, the stdio shim, two test fixes, and the measured evidence. See the
[findings](../conformance/v0.8.2/findings.md) for the matrix, the product
clients, and cleanup.

## Review corrections

| Change | Verdicts | Resolution |
| --- | --- | --- |
| Protocol gap tests (`task_surface_conformance.rs`) | MERGE-WITH-FIXES, fixes verified | Empty excluded upstream fields now carry the credential sentinel and are checked before the mock serves them; held admission uses an explicit release gate with a watchdog instead of timing |
| Stdio shim (`scripts/mcp-stdio-shim.sh`) | BLOCK twice, then MERGE | Byte-identical relays, EOF and signal forwarding, exit status, private file modes, refusal inside a work tree, no output of its own |
| Shim startup signal | MERGE-WITH-FIXES, fix made | On Bash 5.2 a trapped signal during startup could lose the child or escape the trap; the input relay is a coprocess, waits target live processes only, and the exit status is 128 plus the signal when the command is already gone |
| Large package scan timing tests | Primary change | The held reads last 8 seconds and the reply must come within 4, so a slow runner cannot fail a correct deadline |
| Product client run | No defect | Claude Code and Codex CLI ran all ten steps on the lab; every outcome is a client behavior recorded in the findings |

A real-client rehearsal before the official run found two harness needs, a
larger Podman machine for the full lab seed and removal of inherited client
session variables, and no server defect.
