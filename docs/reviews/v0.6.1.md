# v0.6.1 release review

The final review closed three findings before release. The review covered the
integration-policy API and CLI, one-shot transport, recorder, fixtures, and
documentation from v0.6.0 through the v0.6.1 candidate.

| Finding | Resolution |
| --- | --- |
| `--all-custom` omitted integrations with protected custom parents | Keep those integrations selected and refuse the export as `unsupported`. |
| Unchanged overwrite targets bypassed the empty-input contract | Apply the package input check to every effective import target, including unchanged rows. |
| Recorder package state could become stale before create | Require installed exact metadata and recheck the exact installed version and complete inventory immediately before bootstrap, recorded, and duplicate creates. |

Each correction has a regression that failed before the fix and passed after
it. Follow-up review found no remaining release blocker. Recorder checks
preserve cleanup ownership and the post-attempt inventory audit. Fleet has no
conditional create, so the final inventory-read-to-create race remains.

The bounded read-only selector consistency follow-up is recorded under the
0.6.2 backlog in [the implementation plan](../plans/v0.6.1.md).

The final local gate covers locked workspace tests, locked Clippy, formatting,
dependency policy, package contents, fixture privacy, and conformance-report
validation. Publishing preflight and CI must pass on the release commit before
the tag is pushed.

The committed fixtures retain the three-flavor measurements from 2026-09-04.
This review ran no new live mutations. The Fleet conformance matrix remains
scheduled for 0.6.2.
