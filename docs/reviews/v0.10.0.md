# elasticctl 0.10.0 review record

0.10.0 manages Elastic value-list content: the `value-lists` commands, value
lists in `state pull`, `diff`, and `push`, and the fourteenth contract,
`value_list_round_trip`. The design took seven review rounds before code.
Each code slice had an independent review on a different model before it
joined `dev-0.10`: Sol implemented and Astra reviewed, and Sol reviewed
Terra's work. Astra's sandbox could not run Cargo, so its reviews were
static; the integrator reran the gates on each change. A final Astra review
traced every write path across the whole range. See the
[findings](../conformance/v0.10.0/findings.md) for the matrix.

## Design changes found during implementation

Recording and implementation corrected the design before the code relied on
it, each in its own PR:

- Values are removed by item `id`, never by value: on `ip_range`, Kibana runs
  a by-value delete as a query that matches every containing range (#140).
- The 409 for deleting a referenced list nests its references under
  `message.error` (#143).
- The remove phase compares item ids with the last read before it, so an
  adds-first change can proceed (#145).
- An absent local `meta` leaves the stack's `meta` alone (#146).
- Uncertain-write continuation, 4xx bodies, mixed read evidence, and updates
  of an already-empty list (#148); the listing request and the test rules for
  faults and unfilterable reads (#152).

## Known limits

- **Exception and rule writes in `state push` still use the retrying
  transport**, as they have since 0.2. A write that commits but answers 5xx
  can be resent; the resend fails as a 404 or 409 rather than writing twice.
  Value-list writes are send-once. Planned for a later release.
- **Nothing locks a list.** Two writers to one list, or anyone editing an
  exception that references a list while elasticctl writes it, must be
  coordinated outside elasticctl (design 6.1).
- **Older binaries.** 0.9.0 to 0.9.3 do not refuse a mirror that holds
  `value-lists/`; use 0.9.4 or later with such a mirror.
