## Corrections from live evidence

- **Case comment read (#113).** On Serverless 9.7.0 a case read carried no
  `comments` array although the comment count had grown, and the contract
  failed three times at that check with clean cleanup. The harness reads the
  comment through `GET /api/cases/{id}/comments/_find`. No runtime path reads
  `comments` from a case read; whole-range pass 2 confirmed it.

## Known limits

- **The scratch live config holds the API key.** As in 0.9.0, deferred to
  0.9.2.
- **The shared permit check proves the fourth admission by timing.** It does
  not gate the release of the held calls; an ordering check tried in 0.8.2
  made other callers timing dependent and was reverted. The gap stays open.

## Evidence limits

- The six new kinds ran live on the current protocol path only. Their frames
  on both paths are checked offline against the real server binary.
- No product client ran for 0.9.1. Model-driven clients run against Hosted
  in 0.9.2 (mutation design D35).
- The reviews were static. CI ran the full suite on each merged head.
