This review covers proposed documentation, not implemented behavior.
Review date: 2026-09-05. Code baseline: `d91edd1`, version 0.6.2.

Scope: [research](../plans/v0.7-research.md),
[MCP design](../specs/elasticctl-mcp-design.md), and plans for

## Findings and decisions

| Finding | Resolution |
| --- | --- |
| Workers could not compile adapters before primary-owned registration | Each serial worker owns its complete module/catalog/dependency/test wiring. Review precedes integration. |
| Public library startup lacked target validation | `serve_io` validates both resolved URLs and timeout before protocol startup, without credentials or network access. |
| A special upstream-size error code had no typed core cause | Use `elastic_unsupported` from core's existing kind. Never parse error text. Oversized undecodable input terminates the connection. |
| String limits lacked an implementation owner | Shared byte/non-whitespace validators and per-field zero-request regressions are assigned. |
| Data-view/dashboard detail models contain raw maps | Define exact top-level projections and explicit nested open objects. Omit data-view mapped fields and dashboard metadata/warnings. |
| Existing Fleet lifecycle cleaned objects before MCP could inspect them | Add a reusable fixture lease in 0.7.1. Retain it across preparation, reads, and cleanup failures; reuse existing ownership logic. |
| The fourth crate preceded authoritative architecture/release updates | Prepare shared spec and `AGENTS.md` changes first; include them with crate introduction. |
| Characterization tests were required to fail artificially | Record their initial result and route actual defects through the regression/fix/review task. |
| Private helpers and an empty foundation catalog made tests unreachable | Use library unit tests for private/synthetic boundaries. Test upstream errors through `stack_info` after it exists. |
| The resolved CLI timeout was not bound to the whole call | Construct `ServerOptions.call_timeout` from the resolved profile timeout and test precedence. |
| Query CLI ownership omitted a possible dispatch edit | Include `main.rs` and the MCP server state in that serial worker's scope. |
| SDK defaults advertised extra revisions and negotiation was ambiguous | Override the exact two-version set. Reject unsupported current metadata and configure the legacy fallback through the SDK. |
| Fleet totals counted objects before local filtering | Derive the exact total from the complete filtered vector before MCP limits. Preserve CLI behavior. |
| Retries could repeat inference work | Use one attempt for query calls, disabling both application and reqwest retries. Ordinary inspection retains existing retries. |
| Internal user-lookup wording could exclude doctor authentication | Exclude internal Kibana assignee/profile routes explicitly; allow public Elasticsearch authentication inspection. |

The design reviewer approved the corrected contracts. The plan reviewer
approved both spec compliance and plan quality. Neither review has remaining
findings. These verdicts do not constitute user approval to implement.
