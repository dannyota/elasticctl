# v0.7.1 development review

Independent source, safety, and final evidence reviews passed with no
remaining findings. All three live checks and final gates passed.

The default MCP catalog has twenty inspection tools. Startup opt-in adds
two synchronous query tools with a separate transport that disables retries.
Product changes, the Fleet fixture lease, and the process/live harness each
received independent review. See the [live findings](../conformance/v0.7.1-findings.md)
for tool coverage, client versions, observed failures, and cleanup.

## Review corrections

| Finding | Resolution |
| --- | --- |
| The default data-view ID schema allowed omission | Require the nullable ID field. |
| Query descriptions omitted accepted-input constraints | Advertise byte, non-whitespace, and forwarding rules. |
| Projection tests missed field types, nullability, or nesting | Check exact schemas and selected runtime output for every new tool. |
| Boundary, cancellation, and channel tests could pass without exercising their intended case | Check accepted ASCII and multibyte bounds, active cancellation, exact routes, and captured stderr. |
| A process router probe accepted any tool error | Require the local invalid-argument result and reject an upstream deadline error. |
| Content fixture errors could include raw CLI output | Collapse them to static failures and test the actual child stderr boundary. |
| Live proof omitted some fields, owned values, rejection cases, or normalized errors | Check all thirteen inspection projections, six empty families, six missing gets, and both query shapes. |
| Cleanup tests did not exercise the production orchestration | Add production-used runners and verify child shutdown, both cleanup owners, baseline auditing, registration before writes, and failure precedence. |
| The missing Cases search shared analyzed terms with the owned title | Use one unique alphanumeric search term. |
| The auto-indexed ES\|QL marker column was expected to be `keyword` | Require the measured `text` type in nonempty and empty fixtures; reject the old expectation. |

The Fleet lease has eighteen safety tests within the fifty-test Fleet group.
The process matrix checks both binary names, both protocols, and both startup
modes. Diagnostic errors include only trusted static labels; a sentinel test
checks that an unknown remote column type cannot enter the error text.
